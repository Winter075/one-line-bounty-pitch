One sentence that pitches a builder on funding a make.fun bounty, naming who puts up the reward, who competes and who wins. `main.ts` writes it to `/output/entry.txt`; no network and no changing values.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
